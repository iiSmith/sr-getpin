# sr_getphonepin

## Script Idea
You can get a phone's PIN using only the phone number, but the phone must be in your inventory.

## Requirements
- [`lb_phone`]([https://lbscripts.com/)
- [`bl_ui`](https://github.com/Byte-Labs-Studio/bl_ui/releases)
- [`ox_lib`](https://github.com/overextended/ox_lib/releases)

## Supported Frameworks
- `qbx`
- `qb`

## Note
⚠️ This script supports **LB Phone** only.
